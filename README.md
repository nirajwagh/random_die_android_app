# Random Die Android App

A simple and minimal **Android dice rolling app**.

Tap the dice to instantly generate a **random dice face**. Designed to be lightweight, distraction-free, and easy to use.

## Features

* Random dice roll on tap
* Simple and lightweight
* Minimal UI
* Fully offline
* No ads

## Download

**[Download APK](https://github.com/nirajwagh/random_die_android_app/releases/latest)**

If Android blocks installation, enable **Install Unknown Apps** for your browser or file manager.
